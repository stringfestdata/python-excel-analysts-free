# Python in Excel: A working tour for Excel analysts

_Cover tagline: Your first Python cell to 10,000 futures_

Excel can do that now? A free live, type-along tour of Python in Excel for people who actually work in spreadsheets.

**Python in Excel: A working tour for Excel analysts** is a short live session for professionals who work in Excel every day and want to see, concretely, what Python inside Excel changes for them.

This is not a full course. It's a practical live walk-through of a few things Python in Excel does well, on real datasets, with an honest note about what it doesn't do yet. We start from a blank Python cell, so no Python experience is needed.

The live session is free to attend, and it is type-along: every example is a few lines, we type them together, and you leave having written real Python in Excel yourself. The recording, the follow-along workbook and all the code are posted, free, to **Python in Excel for Analysts: The Free Sessions** on Gumroad within a few days: https://stringfestdata.gumroad.com/l/pxlaf

### **What we'll cover**

We'll walk through 3 parts drawn from my book, *Python in Excel for Data Analytics* (Packt):

#### **Your first Python cell**

hello, world; reference the object from C3; the ordering error.

#### **Your first DataFrame**

load a table into a DataFrame; a bigger table: sales_df.head(); descriptive statistics in one line; the PivotTable in one line.

#### **Two things Excel couldn't do last year**

small multiples in one line; 10,000 futures: a Monte Carlo profit histogram.

The focus is not just on how the code works, but when it's worth reaching for and what Excel problem it solves.
