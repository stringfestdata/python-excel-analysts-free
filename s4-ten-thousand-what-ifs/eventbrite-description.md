# Python in Excel: 10,000 what-ifs

_Cover tagline: 10,000 what-ifs in one Python cell_

Scenario Manager gives you three cases. Simulation gives you all of them. A free live, type-along session on Monte Carlo simulation and worksheet-driven Python in Excel.

**Python in Excel: 10,000 what-ifs** is a short live session for professionals who work in Excel every day and want to see, concretely, what Python inside Excel changes for them.

This is not a full course. It's a practical live walk-through of a few things Python in Excel does well, on real datasets, with an honest note about what it doesn't do yet. No Python experience is needed; if you've never opened a Python cell, the first minutes catch you up.

The live session is free to attend, and it is type-along: every example is a few lines, we type them together, and you leave having written real Python in Excel yourself. The recording, the follow-along workbook and all the code are posted, free, to **Python in Excel for Analysts: The Free Sessions** on Gumroad within a few days: https://stringfestdata.gumroad.com/l/pxlaf

### **What we'll cover**

We'll walk through 3 parts drawn from my book, *Python in Excel for Data Analytics* (Packt):

#### **10,000 what-ifs: Monte Carlo in one cell**

the profit model: demand in, profit out; the whole distribution: a histogram with mean and break-even lines; any 'how often' question is one line.

#### **Python that a manager can use: input cells and dropdowns**

a moving average over a noisy daily series; let a worksheet cell drive the window.

#### **Which decision? Percentiles and a comparison**

percentiles for planning; which decision? Compare two inventory levels.

The focus is not just on how the code works, but when it's worth reaching for and what Excel problem it solves.

### **Who this is designed for**

This session is for people who build or maintain Excel workbooks as part of their job.

It will be most useful if you've run into things like:

- decisions made on a single 'best guess' number
- what-if analysis limited to a handful of hand-picked cases
- Python that only you can run because there's no input cell for anyone else
- no way to compare two decisions on the same set of futures

Typical attendees include:

- business, financial and operations analysts
- professionals responsible for reporting or forecasting
- Excel power users who want a real analytical toolkit without leaving the workbook
